2) 이 폴더의 내용 전체(index.html, r01~r10.html, img, pdf)를 저장소 맨 위에 올린다.
3) 저장소 Settings → Pages → Branch: main / (root) → Save
4) 몇 분 뒤 https://geominguy.github.io/gilajabi-final/ 에서 열리는지 확인한다.
